# Product Requirements Document

## Problem

Comic and manga localization still requires a fragmented workflow across cleaning, redrawing, OCR, translation, typesetting, and export tools. Existing tools either automate too little or remove too much human control.

## Users

- solo translators and redrawers
- scanlation teams
- localization studios
- comic production freelancers

## Job To Be Done

Help users turn raw comic pages into editable, translated, typeset, exportable deliverables with much less manual labor and without losing artistic control.

## Primary User Outcomes

- clean text quickly
- preserve artwork quality
- review and edit AI decisions
- place translated dialogue elegantly
- finish inside Photoshop when needed

## Must-Have MVP Capabilities

- upload page assets
- detect text regions
- review and fix masks
- generate cleaned art
- extract or import text
- match text to balloons
- auto typeset dialogue
- export editable deliverables

## Non-Goals For MVP

- full collaborative editing
- billing
- complex account roles
- advanced translation memory
- SFX recreation automation

## Main Risks

- cleanup quality on complex scenery
- incorrect text-to-balloon matching
- poor default typography
- PSD export limitations

## Product Bet

Users will accept an AI-first workflow if the review loop is fast, output quality is trustworthy, and Photoshop remains a viable finishing step.
